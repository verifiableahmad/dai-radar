### Related, not yet tied to a tracked system

- **Communication-efficient threshold-CKKS aggregation for cross-silo
  federated learning** (ePrint 2026/2897): threshold CKKS without a
  trusted key dealer, with server-side weighting and dropout-aware
  reaggregation. Security is proven for fixed cohorts without dropout
  against a semi-honest server colluding with up to c clients. It
  reports 1.78x plaintext communication on CIFAR-10. Field: secure
  aggregation. Flower's SecAgg/SecAgg+ are mask-based, so
  systems/flower.md is unchanged.
- **Stealing exact training data from other clients during federated
  learning** (arXiv 2611.24689): a malicious client recovers other
  clients' sentences exactly from FedAvg aggregates by iteratively
  subtracting the gradients of sentences already recovered, up to
  80.2% of sentences in its tested setting. Field: federated learning
  privacy. It attacks the aggregate itself, which secure aggregation
  does not hide; no tracked system file claims otherwise.
