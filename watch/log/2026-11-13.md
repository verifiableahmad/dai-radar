### Related, not yet tied to a tracked system

- **VRMaaS: verifiable reward-model-as-a-service** (arXiv 2611.14984):
  sum-check/lookup proofs of Transformer reward-model scoring (1B–8B),
  bound to request, weights and configuration, with an optional
  on-chain ZK wrapper (~217K gas). It reports that a generic wrapped
  inference proof still verifies after six kinds of service-field
  substitution. Field: ZKML / verifiable inference.
- **SecDVA** (arXiv 2611.15373): a maliciously secure (2+1)-party MPC
  protocol, using function secret sharing, for valuing a seller's data
  against a buyer's model before purchase. Field: MPC for ML / data
  markets. No tracked data-market system is named.
- **Batch, Pack, and Prove** (arXiv 2611.16922): more efficient
  succinct arguments for CKKS computations, building on Cascudo et al.
  (CRYPTO 2025), evaluated on a generic neural network. Field: FHE for
  ML plus verifiable computation.
- **Signed dyadic path encoding for private decision trees over TFHE**
  (arXiv 2611.16818): one PBS per leaf-parent instead of per leaf,
  1.5–2× faster for depth ≤4 trees and boosted ensembles. Field: FHE
  for ML. It does not name Concrete ML.
