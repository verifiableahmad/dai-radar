### Related, not yet tied to a tracked system

- **Signed dyadic path encoding for private decision-tree evaluation
  over TFHE** (arXiv 2611.16818): cuts programmable bootstraps from one
  per leaf to one per leaf-parent, nearly halving cost, with failure
  below 2^-64 at 128-bit security. Field: FHE for ML. It is a research
  encoding, not a change to Zama's library, so
  systems/zama-concrete-ml.md is unchanged.
- **VRMaaS: verifiable reward-model-as-a-service** (arXiv 2611.14984):
  binds each reward score's proof to the request, committed weights,
  verifier and configuration, after showing that a generic inference
  proof stays valid under six kinds of field substitution. An optional
  on-chain ZK wrapper attests to selected checks. Field: ZKML /
  verifiable inference. No tracked system uses it.
- **Infrastructure for verifiable AI: where proof costs go** (arXiv
  2611.17042): a survey plus the authors' measurements of six provers
  and seven kernels on transformer inference and LoRA fine-tuning. It
  reports that the dominant cost shifts with proof system and input
  length. Field: ZKML. It measures provers; it does not report on any
  tracked system.
- **SecDVA: maliciously secure MPC data valuation** (arXiv 2611.15373,
  accepted at ICDE 2027): a (2+1)-party function-secret-sharing
  protocol that lets a data buyer measure a seller's data against its
  model, with neither side revealing data or model. Field: MPC for ML /
  data markets. No tracked system uses it.
