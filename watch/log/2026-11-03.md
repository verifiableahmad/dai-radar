- **Opacus, checked against systems/opacus.md (no edit):** "Sensitivity
  Inflation from Cross-Record Precision Routing in Private Quantized
  Fine-Tuning" (arXiv 2611.01411) argues that DP-SGD with LoRA on a
  frozen LLM.int8 backbone breaks the per-record sensitivity premise.
  LLM.int8 picks its high-precision outlier columns over the whole
  batch, so one record changes how other records' activations are
  computed. The authors audit a bitsandbytes + PEFT + Opacus stack and
  report a constructed witness at 15x the add/remove bound. On a real
  model the excess is small (1.065C on the top pair). Their release-level
  audit gives an epsilon lower bound of 3.25, which is below the
  advertised 4.38, so it does not show a violated guarantee. The
  mechanism they describe lives in bitsandbytes' quantization routing,
  not in Opacus's DP-SGD. The Guarantee row ("(epsilon, delta)-DP via
  DP-SGD") still describes what Opacus itself provides, so the file is
  unchanged. This is one unreviewed preprint. If it is confirmed, or if
  Opacus or bitsandbytes respond, a scoped Known limitation (inferred)
  on quantized-backbone fine-tuning may be warranted. For now this is
  worth a manual look, not a matrix change.

### Related, not yet tied to a tracked system

- **VeilFL: two-stage accountability for anonymous federated learning**
  (arXiv 2611.01082): adds round pseudonyms, duplicate detection and
  threshold-committee tracing to PINE (USENIX Security '24), so a client
  identity is opened only after enough linked faults. The authors claim
  PINE's privacy and validity guarantees are preserved, and report
  millisecond-scale prototype costs. No tracked system uses PINE. Field:
  Federated learning / confidential aggregation.
- **CipherFlow: compiling AI programs for cryptographically secure
  inference** (arXiv 2611.01450, accepted at NeurIPS 2026): a compiler
  that plans where to use HE and where to use MPC for a model graph on a
  given hardware and network setup. It reports up to 16.5x speedup on
  BERT-base over static hybrid placement. It is not tied to Concrete ML,
  which is TFHE-only. Field: FHE for ML / Secure MPC for ML.
- **Open Inference Market: a peer-to-peer system for AI inference**
  (arXiv 2611.01865): proposes "earnings as collateral", where a
  worker's unsettled earnings are slashed if a random replay audit
  catches cheating. In a simplified model the authors claim the number
  of audits needed is constant per worker per day. It is a model and a
  proposal, not a deployed network. Field: Decentralized inference
  marketplace (and Optimistic on-chain AI verification). No tracked
  system uses it.
